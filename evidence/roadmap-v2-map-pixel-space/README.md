# Исправление пиксельных координат карты — проверено на TSPS

## Результат

- Владелец повторно запустил обычную установленную игру и подтвердил: все локации карты отображаются.
- `map-after.png` и независимый `owner-ordinary-map.png` показывают пять пунктов: Thousand Snakes Gulch, Orehole Mine, Boring Springs Boneyard, The Town of Boring Springs, The Fricker Gang's Hideout. Три NEW находятся у Mine, Boneyard и Hideout. Рисунки и подписи внутри листа.
- `map-before.png` — прежний дефект на том же контрольном сейве: Gulch слишком низко, Mine обрезана правым краем экрана за пределами листа.
- Это исправление repack, не изменение прогресса, сохранения, UV или общего shader transform. Прежнее объяснение «игра рисует только то, что запросила» отозвано.

## Причина и границы изменения

Однокадровая трасса использует реальные индексы draw, исключая неиспользуемые промежутки общего vertex buffer. Viewport и матрица листа корректны, но координаты части значков и текстов оказываются за экраном.

В реальном desktop reference `Map.Start` получает масштаб из высоты `Sprite.rect` фона, а центр значка включает половину ширины `Sprite.rect`. Координаты локаций заданы в исходных пикселях. Уменьшение rect и PPU вместе сохраняло UGUI-размер листа, но не эту систему координат.

Repack теперь защищает исходные размеры текстур динамических карт и их Sprite-метаданные от обычного и дополнительного mip promotion. Проверенная обрезка mip-хвостов остаётся разрешённой. Классификация узкая: фон/иконки карты, не все world-объекты со словом map.

Независимая проверка всех 53 965 объектов:
- 57 текстур карт сохраняют исходные размеры и level-0 bytes;
- 57 зависимых Sprite сохраняют исходные serialized bytes;
- относительно M4 изменились только 23 Texture2D и 23 Sprite;
- остальные 53 919 объектов побайтно совпадают с M4.

Первый кандидат с keep-id из старого рецепта отвергнут: он дополнительно менял атлас персонажа. Установлен только второй кандидат, прошедший проверку неизменности остальных объектов.

## Идентичности и воспроизведение

- ELF: `9c1ca784d2bfe8fe2dcb9cee85844e1ac76d6840301e085032c6c420de6d03be` (ARM64, 1 955 848 bytes).
- Прежняя section: `a25600cebbd47376d9520d2c4d648463a78911224e8bc82e645dcab6223deb36`.
- Установленная section: `49bd16718ed0dc46f16599255791c7603e8aa2b5f04898784a39d6cacb9d0722`.
- Новый core: `2561879e0685b2a71008dfe90ff2564bf0e1c7452cb3d7f541f8df08cf3ec12f`, 144 392 040 bytes.
- Рецепт: исходный owner core → `tools/wol_memory_repack.py ORIGINAL OUT --repair-sprites --max-mip-levels 1 --levels-file ACCEPTED_M4_LEVELS.tsv`. Не использовать уже перепакованный вход и не добавлять keep-id из исторического рецепта.
- Проверка: `tools/verify_wol_map_pixel_space.py --original ORIGINAL --baseline M4 --candidate OUT/core --out REPORT.json`. По умолчанию ожидается один mip; `--max-mip-levels N` задаёт явный контракт.
- Сборка диагностического ELF выполнена из manifest-pinned BASE с overlay; проверены все 199 native файлов (`overlay-verification.json`).
- Backup прежней section остаётся на устройстве. Payload manifest и установленный SHA проверены независимым чтением.

## Проверки и review

- 32 memory/hazard теста и 24 теста metadata/verifier/wave2/parity проходят. Семь новых verifier-тестов сначала падали из-за отсутствующего проверяемого контракта, затем прошли.
- Pipeline-тест исполняет настоящий `main`: карта не уменьшается даже при extra-level override, но её mip-хвост обрезается; Sprite остаётся прежним. Только источник owner bundle заменён синтетическим fixture.
- 11 source-contract CLI проверок и 22 ARM64/QEMU probe-теста проходили для измеренного ELF.
- `mappixels1`: завершение owned-сессии проверено, SHA исходных сейвов восстановлены, сохранён настоящий KMS-кадр Spruce. Новый пользовательский процесс — отдельная owner-сессия, не объект cleanup.
- Два независимых review выполнены. Реальные пробелы закрыты тестом взаимодействия promotion/strip и явным/тестируемым mip-контрактом verifier. Диагностическая трасса публикуется отдельно от repack fix.
- Два утверждения standards review не подтвердились: измеренный C уже собран с `-Wall -Wextra -Werror`; `words` — нулём инициализированный массив из 96 float, поэтому печать 36 элементов при 32 доступных входных float не является чтением за границей массива. Недоступный хвост нулевой.

## Не является оптимизационным выигрышем

Восстановление корректности увеличило serialized texture payload на **42 958 848 bytes**. Это не измеренная прибавка к физической RAM.

Пассивное окно ordinary owner-карты: 20 отсчётов, PSS 425.5–429.6 MiB, SwapPSS 492.1–497.7 MiB, MemAvailable 62.6–91.9 MiB, CmaFree 2.1–7.2 MiB, Mali context commit 278.9–283.0 MiB. Подробности и стоимость sampler — `owner-passive-memory.json`. Эти пересекающиеся поля не суммируются. Нет matched A/B и полного per-present clock: FPS и причинная RAM-дельта не заявляются. Zero-swap остаётся недостигнутым.

Owner bundle, section, кэш, сейвы, desktop reference и извлечённый игровой код не публикуются.
