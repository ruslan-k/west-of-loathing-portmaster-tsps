# GPL runtime overlay

The owner-supplied upstream runtime and nxgl source patches reconstruct the 435-file baseline pinned by `source-manifest.sha256`. Their source provenance is documented in `../docs/upstream-source.md`.

`wol-adapter.patch` is our GPL-3.0 modification overlay. The build applies it to a fresh verified baseline copy; no third-party ELF, owner NSO/RomFS or generated shader bytes are included. The overlay is what turns the recovered baseline into the running adapter: the owner-accepted 720 `UpRender` size rewrite, the sparse `TransferMemory` copy, diagnostics and fail-closed guards are all in this tree. Current acceptance and open rows are in [`../evidence/release-720/README.md`](../evidence/release-720/README.md) and roadmap §18; source parity between the manifest-pinned baseline, this overlay and the measured native tree is recorded in [`../evidence/source-parity/README.md`](../evidence/source-parity/README.md). Historical note: an earlier revision of this file described the overlay as reaching shader capture only — that is obsolete. See `../docs/tsps-horizon-adapter.md`.
